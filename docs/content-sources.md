# CodeGo! — Fuentes de Contenido

## Política General

**Todo el contenido educativo de CodeGo! es original**, creado específicamente para la plataforma.

Las plataformas externas se usan únicamente como referencia pedagógica conceptual.

## Contenido Original CodeGo!

Todo el contenido en `/supabase/seed/` es propiedad de CodeGo! y ha sido creado originalmente:

- Lecciones explicativas
- Ejercicios de todos los tipos
- Pistas (hints)
- Mensajes de Byte
- Textos de UI
- Nombres de mundos y cursos

## Proceso de Adición de Nuevo Contenido

```
1. Verificar licencia de la fuente
2. Determinar si puede reutilizarse o solo inspirarse
3. Crear contenido original basado en referencia
4. Documentar en esta tabla
5. Añadir al seed con metadata de autoría
```
